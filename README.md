# Kweku Anyen — portfolio

Personal site in the register of [Brand Appart](https://www.brandappart.com/): Next.js, GSAP, Lenis, cream field, Youth-like display type, stacked scroll on “What I ship.”

## Stack

- Next.js 16 (App Router) + React 19 + TypeScript
- Tailwind CSS v4
- GSAP + ScrollTrigger
- Lenis smooth scroll

Brand Appart’s live site is Next.js + GSAP + Sanity, with Youth and PP Neue Montreal. Those two faces are licensed, so this build uses Syne ExtraBold and Geist as the nearest freely licensed pair, plus IBM Plex Mono (same as theirs).

## Run

```bash
npm install
npm run dev
```
